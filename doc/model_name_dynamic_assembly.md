# 型号动态拼装规则

XM 工程版固件在 `0x120` Model 为全 0 时，运行期按 `0x148` 掩码把若干段拼成 40 字节型号串，写入 NVMe Identify Controller 的 MN（字节 24–63）和 SCSI INQUIRY 型号串。本文是工具菜单 4「动态拼装」与菜单 1/6 展示的规则依据。

## 触发条件

| 偏移 | 长度 | 含义 | XM | GD |
|---|---|---|---|---|
| `0x10C` | 20 B | SN，不参与拼装 | `29036200000000000001` | `NA6169D003A74` |
| `0x120` | 40 B | Model：首 dword ≠ 0 时**原样使用**，全 0 时走动态拼装 | 全 0 → 动态 | `E2M2 64GB` → 静态 |
| `0x144` | 4 B | **全 0，不是字段**（掩码在 `0x148`，别混） | `00000000` | `00000000` |
| `0x148` | 1 B | 拼装掩码，仅首字节有效（后 3 字节为 0） | `0xBC` | `0xBD` |
| `0x14C` | 8 B | OEM 串，由 `0x40` 位控制 | `OEM` | `OEM` |
| `0x154` | 8 B | MID 段厂商名覆盖串 | 空 | 空 |
| `0x15C` | — | 紧随 `0x154` 的**在用字段**，`0x154` 写入不可越界 | — | — |

> 以上偏移与取值已用 `FIRMWARE/` 四个 `.bin` 的 1KB 头逐字节核对：`0x148` 是 `0xBC`/`0xBD`，`0x144` 恒为 0。

## 拼装顺序与位掩码

主函数是一串 `if`，按位 **7→0** 依次追加到 40 字节缓冲；只有置位的段才追加，分隔符是 `-`（不是空格）。**总长 > 40 则整个放弃，型号保持空。**

| 位 | 名称 | 追加内容 | 来源 | 头里能否改 |
|---|---|---|---|---|
| `0x80` | VEN | `BAYHUB `（7 B） | 固件 rodata | 否 |
| `0x40` | OEM | `0x14C` 字符串（≤8 B） | 头字段 | 可 |
| `0x20` | MID | eMMC 厂商名 + `-` | 运行时 CID[0] → rodata 厂商名表；`0x154` 非空时覆盖 | 仅覆盖串 |
| `0x10` | PNM | 6 B 产品名 + `-` | 运行时 CID[3..8] | 否 |
| `0x08` | FWVER | `0x` + 4 hex + `-` | 运行时版本值 | 否 |
| `0x04` | CAP | 数字 + `GB ` | 运行时 CSD/EXT_CSD 容量 | 否 |
| `0x02` | — | 未使用 | — | — |
| `0x01` | DISK | `Disk` | 固件 rodata | 否 |

**位名以反汇编为准**：`0x20=MID`、`0x10=PNM`、`0x08=FWVER`、`0x04=CAP`。这四位顺序容易记反（`cap/fwver/pnm/mid` 是错的），按名字单独增删字段时务必对照本表；默认掩码 `0xBC` 把这四位全置，固定使用该掩码时不受影响。

工具**固定使用 `0xBC`**（`0x80|0x20|0x10|0x08|0x04`），不提供逐位选择。真机例：
`BAYHUB Samsung-CKTM4R-0x0012-64GB `。

## `0x154` 厂商名覆盖串

固件按 eMMC CID[0] MID 查内置厂商名表，命中即自动识别以下 13 家，此时 `0x154` **留空**：

`Union / Micron / Toshiba / Samsung / Hiksemi / SanDisk / Phison / Hynix / Foresee / YMTC / Ramaxel / Biwin / Kingston`

表外厂商才需自定义覆盖串，两条硬约束（真机核对结论）：

1. **固件不会自动补分隔符 `-`**，写入值必须自带。工具 UI 输入上限 7 B，程序在末尾补 `-` 后正好占满 8 B（如 `ACME` → 写入 `ACME-`，型号段为 `BAYHUB ACME-…`）。
2. `0x15C` 是被使用的头部参数字段，`0x154` 写入**绝不能超过 8 B**，否则越界破坏它。

## 头里能改 / 不能改

| 类别 | 内容 | 是否需重算校验 |
|---|---|---|
| 客户参数区 `0x000–0x3FF` | `0x120` Model、`0x148` 掩码、`0x14C`、`0x154`、`0xCD`、`0x105` | **否**，不在校验范围 |
| 固件 rodata | `BAYHUB `、`Disk`、`GB `、`0x`、`-`、厂商名表 | 需改镜像 body，并重算 DWORD31 |
| 运行时 eMMC 数据 | CID 的 MID/PNM、固件版本、容量、卡数 | 头里根本没有这些字段，改不了 |

因此 MID/PNM/FWVER/CAP 是运行时值，镜像内无法精确预览；工具在屏上用真机抓包值作示意并明确标注。
